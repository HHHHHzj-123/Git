## 文件存放与归类

用户指定的统一资料根目录：`C:\Users\HZJ\Desktop\财务管理实操`。

本知识库导航文件存放于根目录下的 `00-知识库与学习导航`。本对话后续生成的相关文件均放入上述资料根目录，按照内容建立子文件夹，并在本导航中登记。

业务内容出现时，按下方模块编号建立对应目录，例如 `02-总账与月结季结年结`、`06-存货与成本`、`09-发票与税务`、`10-财务报表与合并报表`；面试专项资料归入 `13-面试与职业发展`。同一主题内容较多时再建主题子目录，相关讲解、表格、案例和检查清单放在一起。

文件名尽量使用“主题编号-主题名称-资料类型”；需要保留版本时附日期。跨模块资料选一个主要归属目录，在导航中交叉引用。现有资料目录不纳入自动重命名或重排范围。

## 学习顺序

1. 建立月结全景：理解结账依赖关系、每个岗位交付什么、总账如何判断可以关账。
2. 掌握核对与高频业务：全科目核对，采购暂估、销售应收、费用、薪酬、资产、资金与税务的衔接。
3. 深入行业难点：制造业存货与成本、科技企业研发与项目核算、贸易企业库存与信用管理。
4. 完成闭环：模拟一个月的业务处理、对账、调整、报表编制与经营解释。
5. 提升管理能力：组织关账、合并报表、预算、财务BP、流程改进与自动化治理。
