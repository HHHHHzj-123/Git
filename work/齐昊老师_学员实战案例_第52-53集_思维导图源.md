# 第52-53集｜企业融资风险与融资决策

> 融资前先回答四个问题：需要多少钱、用多久、钱具体投向哪里、总成本与风险能否承受。第52集先测资金缺口和短期偿债，第53集接着看长期债务承受力，再比较向内释放营运资本与向外融资的路径。融资只能缓解资金约束，无法替代产品、商业模式与组织效率的改善；选择股权融资时还要计算稀释、对赌和控制权影响。

## 一页总览
### 第52集 融资四问
- 融多少 → 融多久 → 钱用在哪 → 能承受多少成本
### 第52集 现金风险
- 预测资金缺口 → 运营资本测算 → 现金比率 → 速动比率 → 流动比率
### 第53集 承接
- 长期杠杆 → 现金转换周期 → 向内释放现金 → 向外选择工具
### 第53集 条款
- 融资期限 → EBITDA与现金流 → 商业模式 → 估值对赌与控制权

## 一、上下集如何连接成一条融资决策链
### 1. 第52集先决定要不要借以及借多少
- 第52集00:15提出融资四问；00:51转入资金缺口；05:12讨论短期偿债能力。它先处理融资需求和近期还款安全。
- 管理动作是建立月度现金流预测和营运资本测算，识别资金最紧的时点，而不是以年度利润或老板直觉决定借款额。
### 2. 第53集接着决定怎样融以及融后怎么办
- 第53集从长期偿债信号切入，随后讨论向内改善、向外融资、工具与期限、EBITDA、经营模式和股权融资条款。
- 两集合看，形成需求测算、偿债审查、内部改善、工具匹配、条款谈判和投后复盘的完整链条。

## 二、融资四问与资金缺口测算 第52集
### 1. 融多少
- 把未来经营、投资和偿债现金流按月展开，找到最低现金余额；所需融资额应覆盖峰值缺口和必要安全垫，并扣除可动用存量现金及已确定的内部现金来源。
- 区分短期周转缺口与长期项目投入。过度融资会产生利息、承诺费和闲置资金成本，也可能诱发低效投资。
### 2. 融多久
- 用资金回收期匹配债务期限：库存和应收周转对应短期工具，设备与长期项目需要与收益形成期相适应的期限和还款安排。
- 不能用到期很近的借款长期占用在回收缓慢的项目中，避免滚续依赖。
### 3. 钱用在哪以及成本上限
- 按用途列示采购、产能、研发、渠道、债务置换或临时缓冲，并写清预计回款、里程碑和失败情景。
- 比较名义利率以外的担保、手续费、保证金、贴现、股权稀释及治理约束；用项目现金回报和风险承受能力判断上限。
### 4. 运营资本金测算
- 从应收账款、存货、应付账款及预收预付变化入手，测算收入增长时新增资金占用。常用直观公式是经营性流动资产减经营性流动负债，口径须按业务调整。
- 大客户回款慢、备货增加和供应商账期缩短，即使利润增长也会加大现金缺口。

## 三、短期偿债审查 第52集
### 1. 三个流动性指标
- 流动比率＝流动资产÷流动负债；速动比率通常剔除存货等变现较慢项目；现金比率关注现金及现金等价物对流动负债的覆盖。
- 三个指标要结合行业、客户集中度、存货可变现性、受限资金和债务到期表看，不能机械套用统一达标线。
### 2. 最重要的是到期现金缺口
- 把未来13周收款、付款、税费、利息和本金逐周预测，列出已承诺但尚未提款的授信与受限制资金。
- 若预测出现缺口，先明确哪个时点、由哪项支出或回款延误造成，再决定调整经营、展期或融资。

## 四、长期债务与营运资本 第53集
### 1. 长期偿债信号
- 视频00:02列出资产负债率、权益乘数和利息保障倍数。分别观察杠杆、权益放大程度和利润对利息的覆盖；还要结合未来现金流、债务契约与集中到期风险。
- 资产负债率升高不必然不能融资，关键在资产质量、现金生成和行业波动；利息保障倍数也不等于本金偿付能力。
### 2. 正确认识CCC
- 视频同一章节提到CCC。现金转换周期通常由存货周转天数加应收周转天数，再减应付周转天数组成，衡量从付出现金到收回现金所需时间。
- CCC缩短能释放营运资金，但它不是直接的长期偿债比率；要同时看是否因压货、拖欠供应商或延迟必要采购而出现表面改善。
### 3. 先向内找现金
- 视频01:16建议先改善应收、供应商和存货管理。可按客户账龄推进催收与信用政策，按商品周转优化采购和库存，并与供应商协商与经营周期匹配的账期。
- 内部改善的优先级取决于释放现金的速度、对客户与供应链关系的影响，以及是否损害长期经营。

## 五、向外融资的工具选择 第53集
### 1. 债务类与交易类工具
- 视频02:17列举银行借款、保理和银行承兑汇票。银行借款要核对利率、期限、担保、还款方式和财务约束；保理要看应收转让范围、有无追索和基础交易真实性。
- 银行承兑汇票改变付款安排，也可能占用保证金或授信，比较时应把资金成本和供应商接受度一并纳入。
### 2. 股权和债券融资
- 股权融资无需像普通借款那样定期偿还本金，但会带来持股稀释、治理权变化和退出压力；债券融资通常涉及发行条件、披露与持续偿付义务。
- 选择工具时对照资金用途、规模、期限、现金流波动、担保能力、控制权容忍度和合规成本。
### 3. 融资期限匹配
- 视频03:21把一年以内、一年至三年、三年以上分别作为短、中、长期的说明。这是视频中的讨论口径，不应视为所有银行、会计或监管场景的统一分类。
- 制作债务到期梯度表，避免同一季度集中偿还；对于固定资产与长期项目，重点校验回收期和宽限期。

## 六、EBITDA与现金流的关系 第53集
### 1. 指标能说明什么
- 视频03:32讨论EBITDA。它从利润口径剔除利息、所得税、折旧和摊销，可辅助比较企业经营成果与债务负担。
- 不同企业对调整项可能有不同定义，使用时应与净利润及财务报表勾稽。
### 2. 指标不能替代什么
- EBITDA不是经营活动现金流净额，未直接反映应收、存货、应付变动，也未扣除维持经营所需资本开支、本金偿还或所得税现金支出。
- 偿债测算应至少并看EBITDA、经营现金流、资本开支后自由现金流和到期债务服务金额。

## 七、融资不能代替经营模式修复 第53集
### 1. 识别结构性亏损
- 视频04:52强调融资只是金融杠杆。如果产品没有竞争力、单位经济模型不成立或组织效率低，新增资金只能延后问题暴露。
- 区分暂时性现金错配与持续性经营失血：前者可考虑短期融资，后者必须先改产品、定价、成本或业务结构。
### 2. B端企业转型
- 视频05:17以toB企业说明产品或商业模式转型。应核对客户获取成本、项目毛利、交付周期、回款条件和复购质量。
- 融资方案中加入经营改善里程碑，按订单质量和现金回收复盘，而不是只看新增授信规模。

## 八、股权融资的三项条款风险 第53集
### 1. 估值与稀释
- 视频06:36提示估值风险。把投前估值、投后估值、新增股份、员工期权池和后续融资列在同一张完全摊薄股权表中。
- 投资金额相同，估值和期权池设置不同，创始人的最终持股可能差很多。
### 2. 对赌与退出
- 逐条核对业绩目标、补偿方式、回购触发、责任主体、付款来源和失败情景；不能只看投资款到账。
- 对赌安排的法律效力、会计分类、税务与公司法限制需要专业审阅。
### 3. 控制权与治理
- 除持股百分比，还应审阅董事席位、重大事项否决、信息权、优先认购、反稀释和清算顺位。少数股权也可能附带较强的治理影响。
- 融资前后分别演练下一轮融资、业绩不达标和创始人离任等情景。

## 九、财务经理的融资决策工作底稿
### 1. 资金需求表
- 列出13周及12个月滚动现金流、峰值缺口、最低现金安全垫、资金用途与预计回收时点。
### 2. 偿债与期限表
- 按月列出本金、利息、租赁与担保义务，配套流动性指标、杠杆、利息保障和压力测试。
### 3. 方案比较表
- 将内部改善、银行借款、保理、票据、债券和股权按可得规模、实际成本、期限、担保、控制权和实施时间比较。
### 4. 决策与复盘
- 向老板给出基准、乐观和压力情景，说明建议工具、触发条件与退出预案；资金到账后持续跟踪用途、回款和债务契约。
