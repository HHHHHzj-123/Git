# 企业财务文件夹模板

## 使用方法

1. 复制“SZ01_示例法人”，按公司代码和名称重命名。多法人集团每个法人建立独立目录。
2. 月度重复资料放在年度下相应业务循环，再按月份细分；跨期合同、借款、资产和长期事项保存原件并建立索引，不要每月复制。
3. `05_工作区`仅用于编制过程，`04_正式归档区`只保存Reviewed、Approved或Final文件。
4. 推荐命名：`期间_法人代码_资料类型_状态_版本_日期`。例：`2026-08_SZ01_银行余额调节表_Reviewed_v02_20260903.xlsx`。
5. 工资、个人身份、银行账户、网银、税务账号和重大合同必须设置最小访问权限。
6. 不要把ERP全量明细再人工抄成Excel。只有系统无法记录的判断、跨系统桥接、责任行动和未决事项才建立辅助台账。
7. 法定会计档案的范围、保管、移交和销毁按现行法律制度执行；到期不等于可以自动删除，涉及未结债权债务和其他未了事项的资料不得销毁。

## 文件状态

- Draft：编制中，允许修改。
- Reviewed：已由复核人检查，修改后需重新复核。
- Approved：已获权限人批准。
- Final：正式对外或正式归档版本，原则上只读。
