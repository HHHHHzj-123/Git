# M06-001 制造业成本与存货完整核算

版本及政策核验日：2026-09-09  
案例公司：远澜增材科技（苏州）有限公司  
案例期间：2026年8月；金额单位：万元

## 本主题在知识体系中的位置

主模块为M06“存货与成本”，连接采购与应付、薪酬、固定资产、销售与收入、总账月结、税务、ERP内控和经营分析。学习主线是：

**采购与入库 → BOM与工单 → 领退料 → 材料、人工、制造费用归集 → 制造费用分配 → 在产品 → 完工入库 → 销售成本 → 毛利 → 盘点与跌价 → 月结复核。**

## 建议阅读顺序

1. 先看《制造业成本与存货核算全景.xmind》，建立物流、信息流和价值流全景。
2. 再读Word手册第1、4、7—12、20、25—28章，掌握工单、分配、在产品、完工、月结和主管复核。
3. 打开Excel的“00-说明与参数”“17-管理看板”，核对贯穿案例结果。
4. 依次完成成本月结清单、收发存、暂估、BOM、工单、制造费用、在产品、完工成本、毛利、库龄、盘点、跌价和异常整改页签。

## 文件说明

- `制造业成本与存货核算全景.xmind`：3张工作表、919个主题，适合快速定位流程、月份案例和异常处理。
- `制造业成本与存货完整核算实操手册.docx`：50页、28章及附录，含流程图、连续案例、成本计算、分录、ERP、税务和16项异常案例。
- `成本与存货月结实操工具.xlsx`：19页签，含公式、校验、异常状态和管理看板，可作为练习底稿改造成企业模板。

## 贯穿案例结果

本期直接材料300、直接人工100、制造费用180，本期生产成本580；月初在产品60、月末在产品115，完工产品成本525。P100本月完工单位成本2.30万元/台，C200为0.20万元/箱；加权平均销售成本347.62，收入710，综合毛利率约51.04%。

## 使用边界

案例中的成本中心、分配基础、完工率、审批阈值和关账日历属于教学企业内部政策。实际工作应结合产品工艺、ERP配置、会计政策、税务所属期、业务证据和审批权限确定。涉及非正常损失、存货跌价、资产损失税前扣除和增值税处理时，应按真实发生日和当期有效规定再次核验。
