# 第17集｜汽车4S店扭亏与内部控制

> 4S店卖车可能依赖厂家、保险和金融返利，真正稳定的利润与现金流往往来自售后。案例通过识别事故车渠道被内部人员和中介控制的问题，重建账号权限、响应时效、返佣审批和客户复购指标，使售后收入增长并推动门店扭亏。

## 一页总览
### 收入结构
- 新车销售与返利 → 二手车/置换与装潢 → 事故车与售后维修
### 经营重点
- 售后高毛利 → 现金流好 → 复购率高 → 作为扭亏突破口
### 风险根因
- 中介渠道占比过高 → 内部员工利益冲突 → 保险账号失控 → 客户被截流
### 整改闭环
- 清理利益冲突 → 权限收回 → 20分钟响应 → 返佣全成本审批 → 复购追踪

## 一、4S店的三类收入来源
### 1. 新车销售及各类返利
- 视频案例中新车直接销售毛利可能为负，盈利依赖主机厂销售返利、保险返利和金融贷款返利。
- 不同车型奖励不同，金融返利通常较高；视频提到中低端车型客户贷款比例约40%，但各品牌和客群差异很大。
- 厂家返利属于可变对价或其他特定安排时，应根据合同条款、达成概率和会计准则确认，不能为完成考核任意高估。
### 2. 二手车、置换和汽车装潢
- 品牌二手车置换可能取得厂方奖励；贴膜等装潢业务通常具有较高毛利，但需求刚性因产品而异。
- 每项业务都应单独核算直接毛利、渠道佣金和客户转化，不能只看收入规模。
### 3. 事故车及售后维修
- 视频给出的普通售后维修毛利率约30%，案例门店可达35%—40%；配件毛利通常也在30%以上。
- 收入由维修工时和材料构成，品牌系统可能固定工时单价，门店通过标准工时、项目组合和效率管理影响收益。
- 工时必须真实合理并向客户透明，不能通过虚增工时侵害消费者权益。

## 二、售后能力取决于技师、产能和库存
### 1. 维修量下降可能引发能力流失
- 事故车和售后业务持续下降时，机修、钣金、喷漆等技师可能流失，门店被迫外包，进而影响交期、质量和投诉率。
- 门店应根据日均进厂台次配置客服、技师和工位，并跟踪工位利用率、技师人效与返修率。
### 2. 配件库存与主机厂信用
- 案例提到主机厂信用额度约有45天免息期；超过期限后产生资金成本。
- 行业承压时门店减少配件库存，客户维修可能需要临时订货；财务要平衡库存周转、缺货等待和客户流失。
### 3. 收款纪律
- 视频指出小额代收或赊账容易形成风险，因此门店要求全额交付后再交车。
- 实际政策应按客户类型、保险理赔和合同安排设计，并确保车辆留置或交付控制合法。

## 三、系统建设要与门店规模匹配
### 1. 大型集团的双系统方案
- 主机厂业务系统通常较封闭，大型连锁集团可在厂方系统之外建设经销商ERP并进行接口整合。
- 该方案需要持续研发、主数据治理和较高资金投入。
### 2. 中小门店的务实方案
- 单店或少量门店可采用厂方业务系统加财务软件，通过规范导入、对账和管理报表补足信息缺口。
- 是否上ERP应基于业务复杂度、门店数量、接口可行性和投资回报，而不是把系统当作管理问题的替代品。

## 四、扭亏突破口：把资源集中到售后维修
### 1. 为什么选择售后
- 相较新车销售，售后维修具有毛利较高、现金流较好、复购率较高和坏账较少的特点。
- 案例企业2024年事故车维修收入较2023年增加120多万元，成为改善经营的重要增量。
### 2. 财务像侦探一样从数据找问题
- 先按渠道、客户、维修项目和责任员工拆分收入、配件成本、外包成本、佣金及返佣后毛利。
- 再把异常数据带回现场验证，识别到底是市场下滑、流程失控还是利益冲突。

## 五、事故车渠道失控的风险画像
### 1. 过度依赖中介渠道
- 案例中中介提供的事故车超过总维修车辆的一半，门店对单一渠道形成持续经营依赖。
- 中介佣金压低毛利，个别维修项目在佣金后甚至出现负毛利。
### 2. 账号和客户被截流
- 中介取得门店保险公司账号密码，并把多家保险公司的联系人改为自己的姓名和手机号。
- 其中两名中介还是门店售后在职员工，客户报案后首先联系到中介，本应属于门店的客户被截流。
- 这同时暴露账号权限、员工利益冲突、客户信息保护和离职交接失控。

## 六、事故车业务的五项整改措施
### 1. 清理利益冲突并收回权限
- 对存在严重利益冲突或违规行为的员工依法调查、保全证据并按劳动制度处理，禁止未经披露的中介身份。
- 保险平台账号由门店授权部门控制，实行实名账号、最小权限、定期改密和操作日志复核。
### 2. 建立20分钟客户响应
- 由客户部门统一接收保险报案，并在20分钟内联系客户；超时可能导致案件流向其他修理厂。
- 响应时效与绩效挂钩，同时监控接通率、到店率和后续转化率。
### 3. 重建返佣追踪与审批
- 返佣追踪表纳入重复供单检查、配件成本、喷漆等外包成本，并计算返佣后毛利和毛利率。
- 案例对返佣后亏损或供单收入低于5000元的申请予以驳回；该门槛为案例规则，应根据本店成本重算。
### 4. 控制渠道占比并考核利润
- 视频建议将中介事故车收入占比控制在20%—30%，降低渠道依赖。
- 事故车相关员工的考核从单纯收入转向毛利、回款、客户满意度和复购。
### 5. 追踪老客户复购
- 客户发生事故后是否再次主动回到门店，是服务信任和渠道归属的直接指标。
- 财务数据应按客户标识统计复购率、流失率和客户生命周期价值。

## 七、全面检查发现的其他漏洞
### 1. 保险与发票风险
- 案例发现疑似通过事故维修骗保的行为，应立即停止、留存证据并按法律及保险合同处理。
- 个别财务人员把客户未索取发票的业务开给其他企业或关联主体，属于严重发票和舞弊风险。
### 2. 砍掉低投入产出项目
- 新媒体投流和佣金投入产出比过低，既未有效引流也未增加销量，应停止或重新设计。
- 厂方认证二手车业务若毛利低且还需向中介补贴，应按真实贡献决定是否保留。
### 3. 财务负责人看板
- 新车返利兑现率、售后收入与毛利、工位利用率、技师人效、返修率、配件周转天数和客户等待天数。
- 事故车渠道占比、返佣后毛利、20分钟响应达成率、客户复购率、账号异常和发票异常。
