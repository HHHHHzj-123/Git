# M02-001 总账会计如何组织并完成一次月结

本专题属于 **M02 总账与月结、季结、年结**，直接关联全科目核对、采购暂估、收入截止、存货成本、薪酬资产、资金税务、报表合并、ERP内控和财务BP。

## 文件顺序

1. `M02-001-总账会计年度工作与月结实战手册.docx`：先看全景图和年度节奏，再按月结日历阅读采购暂估、成本结转、往来清理、账税核对和报表勾稽，最后练习制造企业案例与面试表达。
2. `M02-001-年度工作与月结执行清单.xlsx`：包含年度工作框架、D-5至D+10月结日历、模块检查清单、科目与报表勾稽底稿、问题跟踪表。

## 使用前提

示例以自然年度、非上市企业、一般纳税人、月度结账为基准。D+7是示例企业内部关账日，不是法律统一期限。上市公司、集团快报、外资企业以及制造、科技、贸易企业应根据披露时限、组织结构、ERP配置和业务特点调整。

税务期限和法源核验截至2026年9月9日。具体申报日仍需结合主管税务机关核定税期、当年节假日顺延和后续政策。

## 建议练习

- 第一次：在Excel的“02月结日历”填入假设公司责任人和实际截止时间。
- 第二次：完成“采购100万元当月入库未收票”的暂估、收票和付款链条。
- 第三次：复算制造案例的完工产品成本440万元，并说明62万元期末在产品的判断证据。
- 第四次：在“04科目与报表勾稽”录入一组模拟余额，用“05问题跟踪”登记未解释差异。

## 后续深化

采购暂估 → 成本结转 → 往来清理 → 账税核对 → 报表勾稽。每个专题继续沿“业务发生 → 原始单据 → 系统操作 → 会计判断 → 会计分录 → 税务处理 → 对账 → 月结 → 报表影响 → 风险点”展开。
