## 学习顺序

1. 建立月结全景：理解结账依赖关系、每个岗位交付什么、总账如何判断可以关账。
2. 掌握核对与高频业务：全科目核对，采购暂估、销售应收、费用、薪酬、资产、资金与税务的衔接。
3. 深入行业难点：制造业存货与成本、科技企业研发与项目核算、贸易企业库存与信用管理。
4. 完成闭环：模拟一个月的业务处理、对账、调整、报表编制与经营解释。
5. 提升管理能力：组织关账、合并报表、预算、财务BP、流程改进与自动化治理。
