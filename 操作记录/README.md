# 操作记录

这里记录我们在对话框里对你电脑做的每一次操作。
目的只有一个：**哪天某个程序出问题，能照着记录一步步退回去。**

## 为什么需要它

装软件、改配置、改环境变量这类操作，本身没有「撤销键」。
记录 + 备份，就是我们自己造的撤销键。

## 目录长什么样

```
操作记录\
├── README.md              ← 你正在看的这个
├── _模板\                 ← 开新任务时，复制这个文件夹
│   ├── 记录.md
│   └── 备份\
└── 2026-09-18-某某任务\
    ├── 记录.md            ← 干了什么、怎么退回去
    └── 备份\              ← 动手之前的原始文件
```

## 每次开工的流程

1. 复制 `_模板` 文件夹，改名成 `<日期>-<任务名>`
2. 填 `记录.md` 里的「开工前的状态」—— **这一步不能省**
3. 每做一步，就在表格里加一行，并写明「怎么撤销」
4. 每完成一步，把改动前的原文件拷进 `备份\`
5. 提交一次 git

## 出事了怎么用

跟 Claude 说：「去 `操作记录\` 里找 `<任务名>`，退回到第 N 步」。
Claude 会照着表格倒着撤销。

## 一条必须说清楚的事

**git 只能帮我们回到「记录文件」的旧版本，不能帮你还原电脑。**

还原电脑靠的是两样东西：
- `备份\` 文件夹里的原始文件
- 表格里「怎么撤销」那一列

所以哪一步没有备份、没写撤销方法 —— 那一步就是回不去的。

## 关于敏感信息

这个仓库是私有的。但仍然建议：**账号、密码、密钥不要写进来。**
写清「改了哪一项配置」就够了，不用抄具体口令。
