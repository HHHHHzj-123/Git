## 三、撤销第 5 步（撤销上传）

**这一步最不好收回，动手前想清楚。**

**办法一：让网上的分支回到这次上传之前**

```
git push --force origin <这次之前的提交号>:main
```

⚠️ `--force` 会改写网上历史。用之前先确认没有别人在用这个仓库。

**办法二：整个仓库清空**

```
git push origin --delete main
```

本地文件一个不少，网上变回空的。

**办法三：不用命令（最省事）**

在 GitHub 网页上把仓库删掉，或者改成私有。点几下就行。

**注意**：以上只是把内容从「最新版本」里去掉。git 的历史里可能仍然留得住这些文件，**要彻底清干净得用专门的工具重写历史**，比较麻烦。所以真正稳妥的做法是**上传前就想清楚**，而不是上传后补救。
