## 三、撤销第 3 步

两个办法，任选一个。

**办法一（推荐 —— 只撤这一条）**

```

```

**办法二（彻底复原）**

删掉 `C:\Users\HZJ\.gitconfig` 这个文件。

因为它在本次操作前**根本不存在**，删掉就是完全回到原样。
副作用：如果你以后还往这个文件里加了别的 git 全局配置，也会一起没了。所以优先用办法一。
