## 三、撤销第 3 步

两个办法，任选一个。

**办法一（推荐 —— 只撤这一条）**

```

```

**办法二（彻底复原）**

删掉 `C:\Users\HZJ\.gitconfig` 这个文件。

因为它在本次操作前**根本不存在**，删掉就是完全回到原样。
副作用：如果你以后还往这个文件里加了别的 git 全局配置，也会一起没了。所以优先用办法一。

## 五、撤销第 5 步（撤销上传）

**注意：这一步比前面的难收回。** 本地删提交很容易，网上删东西要另发一个「删除」指令。

**办法一：把网上的分支删掉（等于让仓库回到空的状态）**

```
git push origin --delete main
```

删完后，本地文件一个都不会少，只是网上又变回空的。

**办法二：只想撤掉某一次上传，但保留仓库**

先在本地回退，再强推：

```
git reset --soft HEAD~1        # 撤掉最近一次提交，文件保留
git push --force origin main   # 把网上的记录也改掉
```

⚠️ `--force` 会改写网上的历史。**只推过给别人、或者别人也在用这个仓库时，不要这么做。** 目前这仓库只有你一个人在用，风险低。

**最省事的办法**：如果只是想「别让人看到」，直接在 GitHub 网页上把仓库改成私有（它本来就是私有），或者删掉整个仓库 —— 这个在网页上点几下就行，不用敲命令。
