# 放宽权限白名单（降低弹窗频率）

- 日期：2026-09-18
- 目标：减少 Claude Code 的权限弹窗频率，同时保留四类高危操作的弹窗提醒
- 风险：中（放宽的是「Claude 能不经询问做什么」，影响面覆盖整台电脑）
- **最后确认正常的步骤**：第 4 步（实测 PowerShell 不再弹窗）

   拦不住能力本身。

### 关于第 3 步（新增的 15 条）

| 加入的规则 | 覆盖什么 | 风险 |
|---|---|---|
| `Bash(powershell *)`、`Bash(powershell.exe *)` | 系统排查、注册表查询、进程检查 | **高** —— PowerShell 什么都能干。本次最关键的一条 |
| `Bash(sleep *)` | 等待 | 无 |
| `Bash(du *)`、`Bash(df *)`、`Bash(stat *)`、`Bash(realpath *)` | 看磁盘占用、文件信息 | 无 |
| `Bash(reg query*)` | **只读**注册表 | 低 |
| `Bash(reg export*)` | 改注册表**之前先做备份** | 低（只写出 .reg 文件） |
| `Bash(winget list*)`、`Bash(winget search*)`、`Bash(winget show*)` | **只查不装** | 低 |
| `Bash(git ls-remote*)` | 探查远程仓库 | 低 |
| `Bash(git config*)` | 读写 `~/.gitconfig` | 低（严格说算「改配置」，用户没点名，是 Claude 自己加的） |
| `Bash(explorer.exe *)` | 打开文件夹 | 低（原来只有 `explorer`，少个 `.exe` 就每次都弹） |

**白名单条目数：56 → 71。**

### 为什么没有用 `permissions.ask` 来强制保留弹窗

配置里有个 `ask` 机制，理论上可以写「PowerShell 里出现 `Remove-Item` 就强制弹窗」。
**没用**，因为通配符语义不确定，很可能根本不生效 —— 那样反而给出一种假的安全感。
所以这四类靠的是**写进 CLAUDE.md 的约定 + Claude 自觉**，不是机制强制。这一点必须记住。

### 关于第 5 步（CLAUDE.md 新增的内容）

在「权限白名单与确认流程的关系」下加了一节，明确四类操作保留弹窗：
**① 删文件/目录　② 改注册表　③ 装/卸软件　④ 推送到 GitHub**，
并要求执行时用本身会弹窗的命令形式（`rm` / `reg add` / `msiexec` / `git push`），**不许包进 PowerShell 绕开**。
